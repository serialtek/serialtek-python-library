.. create-capture-settings

Capture settings need to be created in the web UI, the same way they would when
doing a normal capture. Go to the :icon:`configure` Capture settings and
configure your desired settings, then save them by clicking on the
:icon:`download` download icon. This will download the settings as
``CaptureSettings.json``.

.. end

.. live-trace-lock-warning

.. warning::

    It is strongly recommended to continue to hold the lock until you are
    finished interacting with the Live Trace. If another user starts a capture,
    the Live Trace will be deleted. Once the Live Trace has been saved, it is
    safe to release the lock and do further analysis using the saved trace.

.. end

.. download-sample-traces

Download sample traces
-----------------------

Several of the examples in this guide make use of sample traces that are
available for the Kodiak. You can download these traces through the Kodiak's
web UI:

Open the :icon:`hdd` media view, and select the :icon:`download` get
sample traces button in the toolbar, then click "Start Download".

This will download the sample traces to their default location at ``/media/SATADrive0/serialtek-sample-traces``.

.. end
